# Celula de Desarrollo - Trabajo Practico

## ¿De qué trata este proyecto?
Este trabajo simula un equipo de desarrollo donde se organiza un proyecto, se programa en Python y se usa GitHub para control de versiones.

## Integrantes del equipo (roles simulados)
- P1: Hugo - organización del repositorio
- P2: Paco - desarrollo del análisis en Python
- P3: Luis - revisión del trabajo

## Estructura del proyecto
- datos: archivos de entrada
- scripts: código en Python
- resultados: resultados del análisis

## Objetivo
Aprender a organizar un proyecto usando GitHub y realizar un análisis básico de datos.

## Escenario elegido
Escenario B - Análisis de ventas de una pequeña empresa

## Ejecución
El script se ejecuta desde la carpeta scripts y guarda resultados en resultados.
